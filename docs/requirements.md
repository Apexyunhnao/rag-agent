# 需求文档 — 知识库问答 Agent（RAG Agent）

## 业务背景

中大型企业内部通常积累大量文档：规章制度、产品手册、FAQ、技术规范、操作流程等。员工遇到问题时的典型路径是：翻共享目录 → 搜文件名 → 打开文档 → 逐页找答案。这个过程耗时且依赖运气，新人尤其头疼。

本项目的假设场景：某 500 人制造企业，有一套《员工手册》（规章制度类）和一份《IT 常见问题 FAQ》。员工想查"年假怎么申请"或"VPN 连不上怎么办"，需要直接得到答案，而不是一个文档链接。

## 目标

把预置的文档向量化存入 ChromaDB，用户以自然语言提问，系统检索最相关的内容片段，由 LLM 生成**带出处的回答**。

核心流程：
1. 文档预置（ingest）：加载 → 分块 → 向量化 → 入库
2. 用户提问 → 检索 Top-K 相关片段
3. 片段 + 问题 → LLM 合成自然语言回答

## 成功指标

| 指标 | 定义 | 目标 |
|------|------|------|
| 检索命中率 | Top-5 片段中包含正确答案的比例 | ≥ 90% |
| 回答准确率 | 人工抽样评估，回答与原文一致的占比 | ≥ 85% |
| 回答耗时 | 从请求到返回完整答案的时间 | ≤ 5 秒 |

## 功能范围

### MVP 包含
- 预置 3~5 份文档（规章制度 + FAQ 类），覆盖 20+ 个常见问题
- 单轮问答：用户提问 → 返回带引用的回答
- HTTP API（FastAPI）：`POST /query` 接收问题，返回 JSON
- 基本日志：记录每次查询的问题、检索结果、回答、耗时到 SQLite
- 简单的 eval 脚本：选 10 个问题做检索命中率和回答准确率评测

### MVP 不包含
- 多轮对话（单轮够用，先验证 RAG 管道质量）
- 文档权限管理（不在求职作品集范围内）
- 对接真实企业文档（预置文档即目标场景）
- 用户登录/注册
- 前端 UI（仅 API）

## 文档清单

预置文档计划（中文，Markdown 格式，放在 `data/documents/`）：

1. **员工手册.md** — 考勤制度、请假流程、加班政策、报销规范
2. **IT 常见问题 FAQ.md** — VPN 连接、邮箱配置、打印机、WiFi、账号申请
3. **信息安全规范.md** — 密码策略、数据分级、U盘使用、远程办公安全
4. **新人入职指南.md** — 入职第一天流程、设备领取、系统账号
5. **绩效考核制度.md** — 考核周期、评分标准、申诉流程

## 非功能性要求
- Embedding 计算走本地 CPU，不依赖外部 API
- LLM 调用走 DeepSeek 兼容接口（成本低、中文好）
- 代码结构清晰，方便面试官快速看懂
- 每个模块有基本的类型标注和中文注释
